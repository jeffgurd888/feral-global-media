# 🐺 FERAL GLOBAL MEDIA

**Untamed stories. Free forever.**

Feral Global Media is the sandbox of Jeffrey Michael Gurd (Nexus Research) — the wild tree in the garden, launched 2026-10-24. This is where imagination plays in public to get a conversation about an idea rolling: comedy, film, books, and visions.

## The sandbox
Ideas start here, out loud. Some graduate to the lab to be proved. Some graduate to the shelf to be sold. Most are here to start a conversation — that's the job.

## The one-way door
Feral may point at the lab. The lab never points back. Attention flows toward the proof; credibility never flows toward the attention. Theorem counts wear the lab's name; punchlines wear Feral's.

**The lab:** Nexus Research — machine-verified mathematics, free forever: [thet-logos](https://github.com/jeffgurd888/thet-logos).
